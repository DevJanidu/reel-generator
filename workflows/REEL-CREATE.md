# Create a Reel

Launch scripts/start.ps1. Settings selects codex_cli (preferred), claude_cli with supported authentication, manual, or openai-compatible. Each has a working Test AI Connection button. Eligible automatic tests validate a real short JSON/nonce response with all four full skills/master included; installation/login alone is not a generation pass. See AI_PROVIDERS.md.

Create New Reel opens the category selector. Choose one of eight groups and 24 genres (or resolve Surprise Me within that group), then confirm the primary genre and provider. POST /api/idea-sessions and its batch endpoint preserve the selection and all batches in an independent workspace. The controller snapshots/reads all full references plus the taxonomy and builds the master/task/schema request. The run is queued with a real ID. Native CLI execution requires verified MXC; model shell/editing/tools are disabled or read-only. Failures never change provider/billing silently.

Exactly five complete typed concepts appear only after schema, identity and diversity checks pass. Generate Another 5 keeps the genre and prior batches, with premise/relationship/conflict comparisons to reduce repetition. Select This Story creates an isolated episode carrying its genre, complete concept and batch provenance into writing. A custom title and optional premise can skip ideation; explicit genre-conflict warnings offer Keep My Premise or Change Genre. Writing and internal retention review both load complete pinned instructions; progress, cancellation, real errors and retry remain visible. Explicit legacy ten-idea requests and older episode snapshots remain compatible. See STORY_IDEAS.md.

Manual exports the same full request for the owner's AI tool. Import writing then the review result. Alternatively save an owner-authored narration/brief; AI review is not claimed. Do not approve an internal review still in progress.

Edit the reviewed draft, then APPROVE SCRIPT & CONTINUE once. Exact narration/hash/version is frozen and auto-export authorized. The model never selects paths or commands. Trusted validation and the scoped writer own all resulting files; no sibling/shared source writes.
