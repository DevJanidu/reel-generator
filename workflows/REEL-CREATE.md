# Create a Reel

Launch scripts/start.ps1. Settings selects codex_cli (preferred), claude_cli with supported authentication, manual, or openai-compatible. Each has a working Test AI Connection button. Eligible automatic tests validate a real short JSON/nonce response with all four full skills/master included; installation/login alone is not a generation pass. See AI_PROVIDERS.md.

Create New Reel calls POST /api/ideas/generate. The controller creates an independent idea workspace, snapshots/reads all full references and builds the master/task/schema request. The run is queued with a real ID. Native CLI execution requires verified MXC; model shell/editing/tools are disabled or read-only. Failures never change provider/billing silently.

Ten typed concepts appear after success. Selecting Story creates an isolated episode and queues writing with automatic providers. A custom premise can skip ideation. Writing and internal retention review both load the complete pinned instructions; progress, cancellation, real errors and retry remain visible.

Manual exports the same full request for the owner's AI tool. Import writing then the review result. Alternatively save an owner-authored narration/brief; AI review is not claimed. Do not approve an internal review still in progress.

Edit the reviewed draft, then APPROVE SCRIPT & CONTINUE once. Exact narration/hash/version is frozen and auto-export authorized. The model never selects paths or commands. Trusted validation and the scoped writer own all resulting files; no sibling/shared source writes.
