# Automatic preproduction

POST /approve records immutable narration and asynchronously queues prepare. Its request includes all four complete pinned skills, pinned master/rules, character/storyboard/Flow/retention/publishing contracts, the exact approved narration/hash and Package schema. One provider coordinates the logical roles without inventing independent story versions.

CLI or explicit API mode returns structured content automatically; manual waits for explicit import. Validate unique scene/cast IDs, complete ordered narration spans, scene-specific fields, protected regions and ten distinct audit criteria before writing. No separate character/storyboard/prompt approvals. Malformed output, contradiction, timeout or usage failure blocks the run with its actual error and local diagnostics.

The scoped compiler writes Character Bible, continuity matrix, narration, provisional storyboard/timeline, retention/style locks, asset manifest, caption specification, music direction and publishing draft. Flow JSON has only schema_version, episode_id and jobs; every job is type:image with source_image:null, stable IDs and a complete self-contained strict-2D portrait prompt. Export all jobs or ten-job batches. Prompt files do not mean images were generated.

Timings remain provisional before narration. Preserve scene IDs/images. Existing episodes use immutable input snapshots even after global upgrades. Validate pinned inputs in the workspace; adopting a new global creative version requires a new episode. Never silently repin or change approved narration. Only complete validated packages become AWAITING_ASSETS.

Requests, responses, schemas, provenance, progress, retries, logs and all production files stay in the assigned episode. Workers cannot modify shared files or SQLite; see SECURITY.md.
